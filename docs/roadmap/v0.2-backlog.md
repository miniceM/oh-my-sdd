# v0.2 Backlog

本清单只记录 npm workspaces 重构后仍可验证的遗留事项。产品由两个锁步发布的包组成：

- `packages/product`：`@cli-tools/oh-my-sdd`，安装器、CLI、hooks、skills 与 baseline。
- `packages/opencode-plugin`：`@cli-tools/oh-my-sdd-opencode`，OpenCode 原生 npm 插件与资源同步。

OpenCode 资源由 npm 插件的 `postinstall` 同步；不再维护或恢复已废弃的根目录 `opencode/` 实现。

## P0：发布前可验证项

- [ ] 在干净的 npm workspace 安装环境运行 `npm test`。
- [ ] 运行 `npm run lint:baseline`，确认 baseline frontmatter、正文 token 限制和 Sync Impact Report 均通过。
- [ ] 运行 `npm run sync:opencode`，确认 OpenCode 插件资源可从 `packages/opencode-plugin` 重建。
- [ ] 运行 `npm run release:check`，确认两个包的锁步版本和发布元数据一致。
- [ ] 分别构建两个包：`npm run build --workspace=@cli-tools/oh-my-sdd` 与 `npm run build --workspace=@cli-tools/oh-my-sdd-opencode`。

## P1：OpenCode 安装与所有权回归

- [ ] 从 npm 安装 `@cli-tools/oh-my-sdd-opencode`，确认其 `postinstall` 在 OpenCode 全局发现目录同步受管 skills、commands 和 baseline block。
- [ ] 验证 `oms-install --tool opencode` 会注册 npm 插件而不覆盖用户已有 OpenCode plugin 配置。
- [ ] 验证重复安装幂等；用户在受管资源外的内容不被删除或覆盖。
- [ ] 验证 `oms-opencode-uninstall` 仅清理由所有权清单记录的资源，并恢复可恢复的备份。

## P1：运行期安全边界回归

- [ ] Claude Code：`PreToolUse` 在写入前拒绝 HARD_RULE，目标文件不落盘。
- [ ] Claude Code：`PostToolUse` 只记录遥测或附加上下文，不作为阻断机制。
- [ ] OpenCode：npm 插件对 HARD_RULE 保持运行期强制；资源同步失败应提供可诊断结果。
- [ ] KiloCode：状态与文档明确标记为 `advisory`，不得声称运行期强制。

## P2：文档与运维一致性

- [ ] 发行前扫描文档、脚本和测试，移除旧单包 `opencode/` 路径与旧生命周期说明。
- [ ] 保持 README、INSTALL、贡献指南、smoke checklist 与本路线图的根命令一致。
- [ ] 每次结构或安全边界变更后更新相关 spike；历史实验结论需与当前生产实现分开表述。

## 不在本 backlog 的事项

已解决的历史 bug、固定测试数量、已废弃目录的迁移方案及过时版本演练不再作为 v0.2 工作项。新增事项必须包含可观察的验收标准与复现/验证命令。
